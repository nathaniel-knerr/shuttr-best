# Shuttr Best

A light-weight web app for editing images

## Project Goals (for MVP)

1. Accept `.png` and `.jpg` files
2. Support cropping 
3. Support grayscale, cool, warm, and enhance filters

## Potential Future Project Goals

1. Use AI image generation to convert input photos into 
professional LinkedIn profile pictures or other useful presets
2. Add spot healing tool using a lightweight image generation model (https://github.com/Picsart-AI-Research/MI-GAN)
